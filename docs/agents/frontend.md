# Frontend

`apps/web` is React 19 + TanStack Router (file-based routes in `src/routes`), Tailwind and a PWA. Shared UI primitives live in `packages/ui`.

## Routes

- `apps/web/src/routeTree.gen.ts` is generated by the TanStack Router Vite plugin from `src/routes/**` on `pnpm dev` or `pnpm build`. Never edit it by hand; it is committed.
- After adding, renaming or deleting a route, run `pnpm build` so the route tree is refreshed.

## Shared vocabulary

- Field limits, enums, Priority labels, List sort fields and Identifier helpers come from `@helios/api/domain`. Use `limits.*` for `maxLength`; never copy a server rule into the web app.

## UI components

- `packages/ui` uses shadcn/ui on **Base UI**. Never add Radix packages.
- Add shared primitives from the repo root: `npx shadcn@latest add <name> -c packages/ui`. Add app-only blocks from `apps/web`.
- Import shared components as `@helios/ui/components/<name>`.
- Design tokens and global styles: `packages/ui/src/styles/globals.css`.
- Pass refs as props; do not use `React.forwardRef` (React 19).

## Skills

- Components, styling, `components.json`: `shadcn`, `web-design-guidelines`.
- React structure and performance: `vercel-react-best-practices`, `vercel-composition-patterns`.
